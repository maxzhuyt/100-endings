## Definitions

- **words**: `len(text.split())` (same as the pipeline's `words`).
- **ends_mid_sentence (rule)**: strip trailing whitespace, trailing decoration-only lines (`---`, `***`, `###`, `~~~`, backticks) and trailing `* _ # ~ \``; complete if the last character is one of `. ! ? … " ” ’ ' ) ] — : ;`, or if the final non-empty line has <= 5 words; otherwise mid-sentence. Empty responses (0 words) are left blank (neither).
- **Manual review**: every rule-flagged story (A), every story made complete only by the <=5-word rule (B), every ending on — : ; (C), 20 random rule-complete stories per run type with seed 0 (D), plus a regex scan of all rule-complete endings for a dangling opening quote, dangling `*`/`**`, or a bare speaker label (scan). All looked-at endings are in `review_endings.txt`; every change is in `overrides.csv`.
- **Run stats set**: ablation = every story file in the dir; paper = iteration 1 (other iterations reported in `n_mid_sentence_other_iters`). `share_mid_sentence` = n_mid_sentence / non-empty stories in that set.
- **at_length_ceiling**: per model over unique non-empty texts; if median(words of mid-sentence stories) >= 75th percentile(words of complete stories), threshold = 10th percentile (nearest rank) of mid-sentence word counts and at_length_ceiling = words >= threshold; otherwise no threshold. The requested raw minimum is reported beside it (`model_ceilings.csv`).
- **mean_nr** = mean over positions with pct >= 10 of (1 - yes_rate); **late_nr** = same over pct >= 80. Run means are unweighted means over judged stories (all stories present in the judge file, not the 15-story selection of ANALYSIS.md).
- **judged_late_march**: the story key is present in a judge file written in 2026-03 (ablation: `results/judge/{config}_judge.json`, 2026-03-29; paper: `ending_judge*.json`, 2026-03-29..31). The no-Step-0 run was judged 2026-06-01 (`judge_ablation/`) with `sbatch/run_judge_rep.py`, whose system prompt and Qwen3-8B model are the same text as the March scripts.
